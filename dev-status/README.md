# dev-status 📊

ดูได้ตลอดว่าใช้ token ไปเท่าไหร่ เหลือกี่ % และ limit แต่ละตัวจะรีเซ็ตเมื่อไหร่ เป็นแถบ progress มีสี อยู่ใต้ช่องพิมพ์

```bash
claude plugin marketplace add sonata39-star/claude-mod   # ครั้งเดียว
claude plugin install dev-status@claude-mod
```

## หน้าตา

> ตัวอย่างวาดจากผลที่ test ตรวจ ตัวเลขสมมติ

**แถบใต้ช่องพิมพ์ (มีสี):**

```
? for shortcuts │ ctx ▰▰▰▱▱▱▱▱ 42% │ 5h ▰▰▱▱▱▱▱▱ 24% ↻14:30 │ 7d ▰▱▱▱▱▱▱▱ 9% ↻จ. 09:00 │ $1.23
```

- ▰ คือ % ที่ใช้ไปแล้ว เต็ม 8 ช่องคือชน limit
- 🟢 เขียว < 60% · 🟡 เหลือง 60–85% · 🔴 แดง > 85% · ช่องว่างเป็นสีจาง
- `ctx` = context window, `5h` = limit 5 ชั่วโมง, `7d` = limit 7 วัน, `↻` = เวลารีเซ็ต
- จอแคบจะย่อเองโดยไม่ตัดขึ้นบรรทัดใหม่: ตัดค่าใช้จ่าย → แท่งสั้นลง → ตัดเวลารีเซ็ต → เหลือแค่ % (`ctx 42% │ 5h 24% │ 7d 9%`)

**status line** เหลือแค่ git กับยอดประหยัดของ rtk:

```
⎇ main ±3 ↑1 │ rtk −13.3M
```

## คำสั่ง

| คำสั่ง | ทำอะไร |
| --- | --- |
| `/usage-bars` | เปิดหน้ากราฟเต็ม (`/usage-bars close` ปิด) |
| `/usage-detail` | สรุปเป็นข้อความละเอียด: token เป๊ะๆ, % ใช้ไป/เหลือ, เวลารีเซ็ต, context แยกประเภท, ค่าใช้จ่าย |

อัปเดตเองหลังทุกงาน หลังแก้ไฟล์ หลัง `/compact` และทุก 30 วินาที

## ตั้งค่า (`/config`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `meterPlace` | `hint` | `hint` = แถบสีใต้ช่องพิมพ์, `status` = ข้อความล้วนใน status line |

บน VS Code หรือมือถือที่วาดแถบใต้ช่องพิมพ์ไม่ได้ จะแสดงใน status line แทนเอง · ยอดประหยัดของ `rtk` แสดงเมื่อมีติดตั้งไว้
