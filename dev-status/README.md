# dev-status 📊

ดูได้ตลอดว่าใช้ token ไปเท่าไหร่ เหลือกี่ % และ limit แต่ละตัวจะรีเซ็ตเมื่อไหร่ เป็นแถบ progress มีสี อยู่ใต้ช่องพิมพ์

```bash
claude plugin marketplace add sonata39-star/claude-mod   # ครั้งเดียว
claude plugin install dev-status@claude-mod
```

## หน้าตา

> ตัวอย่างวาดจากผลที่ test ตรวจ ตัวเลขสมมติ

**แถบใต้ช่องพิมพ์ (มีสี)** อยู่บรรทัดของตัวเอง ใต้บรรทัด hint ของ Claude Code:

```
>> auto mode on (shift+tab to cycle) · ← for agents · ↓ to manage
⎇ main ±3 │ ctx ━━━───── 34% │ 5h ━━────── 27% ↻00:40 │ 7d ━━────── 30% ↻12:00 │ $32.02 │ rtk −13.3M
```

- `━` คือส่วนที่ใช้ไปแล้ว `─` คือส่วนที่เหลือ เต็ม 8 ช่องคือชน limit (ใช้เส้นที่ terminal วาดเอง ช่องเต็มกับช่องว่างจึงขนาดเท่ากันทุก font)
- 🟢 เขียว < 60% · 🟡 เหลือง 60–85% · 🔴 แดง > 85% · ส่วนที่เหลือเป็นสีจาง
- `⎇` = git branch (±ไฟล์ที่แก้ ↑commit ที่ยังไม่ push), `ctx` = context window, `5h` = limit 5 ชั่วโมง, `7d` = limit 7 วัน, `↻` = เวลารีเซ็ต, `rtk` = token ที่ rtk ประหยัดให้
- จอแคบจะย่อเองโดยไม่ล้นบรรทัด: ตัด rtk → ตัด git → ตัดค่าใช้จ่าย → แท่งสั้นลง → ตัดเวลารีเซ็ต → เหลือแค่ % (`ctx 42% │ 5h 24% │ 7d 9%`)

**`/usage-bars`** เปิดหน้ากราฟเต็ม (`╎` = จุดที่จะ auto-compact) กด Esc ปิด

```
Context  ใช้ไป 42% · เหลือ 58%
━━━━━━━━━━━━━━━━━──────────────╎───────
84,000 / 200,000 tokens · auto-compact ที่ 160k ╎

5-hour limit  ใช้ไป 23.5% · เหลือ 76.5%
━━━━━━━━━───────────────────────────────
รีเซ็ต 14:30 · อีก 2ชม 13น

7-day limit  ใช้ไป 9% · เหลือ 91%
━━━━────────────────────────────────────
รีเซ็ต จ. 09:00 · อีก 2วัน 20ชม

Context แยกตามประเภท
━━━━━━━━━━━━━━──────────────────────────
━ Messages 67k  ━ System tools 12k  ━ System prompt 3k
Cost $1.23 · อัปเดต 12:17 · รีเฟรชทุก 30 วิ
```

**เตือนด้วย toast** เมื่อ limit ไหนใช้ถึง 80% และ 95% และเมื่อ context ถึง 80%

## คำสั่ง

| คำสั่ง | ทำอะไร |
| --- | --- |
| `/usage-bars` | เปิดหน้ากราฟเต็ม (`/usage-bars close` ปิด) |
| `/usage-detail` | สรุปเป็นข้อความละเอียด: token เป๊ะๆ, % ใช้ไป/เหลือ, เวลารีเซ็ต, context แยกประเภท, ค่าใช้จ่าย |

อัปเดตเองหลังทุกงาน หลังแก้ไฟล์ หลัง `/compact` และทุก 30 วินาที

## ตั้งค่า (`/config`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `meterPlace` | `hint` | `hint` = แถบสีใต้ช่องพิมพ์, `status` = ข้อความล้วนใน status line (ไม่มีสี) |

บน VS Code หรือมือถือที่วาดแถบใต้ช่องพิมพ์ไม่ได้ จะแสดงใน status line แทนเอง · ยอดประหยัดของ `rtk` แสดงเมื่อมีติดตั้งไว้
