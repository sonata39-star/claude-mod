# done-notify 🔔

สั่งงานไว้แล้วไปทำอย่างอื่นได้เลย พอ Claude ทำเสร็จ หรือรอให้คุณตอบ จะมีเสียงกับ notification เรียก

```bash
claude plugin marketplace add sonata39-star/claude-mod   # ครั้งเดียว
claude plugin install done-notify@claude-mod
```

## หน้าตา

> ตัวอย่างวาดจากผลที่ test ตรวจ

```
╭ toast ─────────────────────────────────────────────╮
│ ✅ เสร็จแล้ว (2m 13s) — แก้ bug login เสร็จแล้วครับ    │
╰────────────────────────────────────────────────────╯
```

พร้อม notification ของ macOS มุมขวาบน

| เหตุการณ์ | เสียง | ข้อความ |
| --- | --- | --- |
| งานเสร็จ (นานเกิน 30 วินาที) | Glass | `✅ เสร็จแล้ว (2m 13s) — <บรรทัดแรกของคำตอบ>` |
| จบด้วย error | Basso | `⚠️ จบด้วย error` |
| Claude รอให้คุณตอบ / ถามคำถาม / dev-guard ขออนุญาต | Ping | แจ้งว่ารอคุณอยู่ (ไม่ถี่กว่า 10 วินาทีครั้ง) |

งานที่คุณกด Esc หยุดเองจะไม่เตือน

## ตั้งค่า (`/config`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `minSeconds` | `30` | งานต้องนานอย่างน้อยกี่วินาทีถึงเตือน |
| `sound` | `true` | เล่นเสียง |
| `systemNotification` | `true` | ขึ้น notification ของ macOS |

ใช้เสียงและ notification ของ macOS
