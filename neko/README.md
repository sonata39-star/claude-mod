# neko ฅ(=•ω•=)ฅ

แมวผู้ช่วยแบบ Jarvis นั่งเหนือช่องพิมพ์ ขยับตัวตามงานที่ Claude ทำ และคอยแนะนำระหว่างทำงาน

```bash
claude plugin marketplace add sonata39-star/claude-mod   # ครั้งเดียว
claude plugin install neko@claude-mod
```

## หน้าตา

> ตัวอย่างวาดจากผลที่ test ตรวจ บนจอจริงหูกับหนวดเป็นสีชมพู ตาเปลี่ยนสีตามอารมณ์

```
  /\_/\        เหมียว · กำลังส่อง test
 (=•ω•=)  ♡    แก้ 5 ไฟล์แล้ว commit ก่อนไหมเหมียว~
  ฅ ⌕ ฅ ~      t: แนะนำหน่อย  h: ซ่อน
```

จอแคบกว่า 60 คอลัมน์จะเหลือบรรทัดเดียว: `ฅ(=•ω•=)ฅ แก้ 5 ไฟล์แล้ว commit ก่อนไหมเหมียว~`

### อารมณ์

| อารมณ์ | หน้า | สีตา |
| --- | --- | --- |
| ปกติ | `(=•ω•=) ♡` | ปกติ |
| ทำงาน | `(=-ω-=)` | เหลือง |
| ดีใจ (มี ♡ ♪ ลอยขึ้นแป๊บนึง) | `(=^ω^=) ♪` | เขียว |
| อุ๊ย (error / ถูกบล็อก) | `(=;ω;=) !` | แดง |
| ง่วง (ว่าง 10 นาที) | `(=ᴗωᴗ=) zZ` | เทา |
| กำลังคิด | `(=•ω•=) ?` | ฟ้า |

ตอนว่างจะกะพริบตาและกระดิกหาง `~` ↔ `ʃ` ทุก 3.5 วินาที

## แนะนำอะไรบ้าง

**ไม่เสีย token:**
- context ≥ 80% → ชวน `/compact`
- ไฟล์ค้างไม่ commit ≥ 8 → ชวน commit
- ทำงานติดกัน 90 นาที → พักสายตา
- เลย 23:00 → ไปนอน
- test fail 3 รอบติด → ให้อ่าน error ช้าๆ

**ใช้ AI (Haiku):** ไม่เกินหนึ่งข้อต่อการสั่งงาน และเฉพาะตอนมีเรื่อง (มี error, งานนานเกิน 2 นาที, แก้ 3 ไฟล์ขึ้นไป หรือทุก 3 งาน)

## ใช้งาน

| คำสั่ง / ปุ่ม | ทำอะไร |
| --- | --- |
| `/neko <คำถาม>` | ถามแมว ตอบโดยรู้ว่าเรากำลังทำอะไรอยู่ |
| `/neko` หรือ `t` | ขอคำแนะนำใหม่ |
| `/neko hide` / `/neko show` หรือ `h` | ซ่อน / เรียกแมวกลับ (จำค่าข้าม session) |

มี agent `neko:advisor` ด้วย สั่ง Claude ได้เช่น "ให้แมวช่วยรีวิวงานหน่อย" แมวจะอ่านโค้ดอย่างเดียวโดยไม่แก้ไฟล์ แล้วตอบเป็นคำแนะนำเรียงตามความสำคัญ

`/neko <คำถาม>` และปุ่ม `t` ใช้โมเดลหลักของ session (ใช้ cache เดิม) ส่วนคำแนะนำอัตโนมัติใช้ Haiku

## ตั้งค่า (`/config`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `animate` | `true` | กะพริบตา กระดิกหาง หัวใจลอย |
| `autoTips` | `true` | ให้คำแนะนำอัตโนมัติด้วย AI |
| `tipModel` | `claude-haiku-4-5-20251001` | model ที่ใช้คิดคำแนะนำอัตโนมัติ |

ตัวอักษรอย่าง `ω` `•` `♡` บาง terminal นับเป็น 2 ช่อง ถ้ารูปแมวเบี้ยวลองปิด `animate` หรือเปลี่ยน font
