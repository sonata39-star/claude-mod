# dev-dashboard 🗂️

เมนูด้านขวาสูงเต็มจอ สรุปว่า session นี้ทำอะไรไปแล้วบ้าง: ไฟล์ที่แก้ คำสั่งที่รัน ผล test สิ่งที่ถูกบล็อก และ pipeline ของทีม (ถ้าติดตั้ง [team-flow](../team-flow/))

```bash
claude plugin marketplace add sonata39-star/claude-mod   # ครั้งเดียว
claude plugin install dev-dashboard@claude-mod
```

## หน้าตา

> ตัวอย่างวาดจากโค้ด layout ที่ 40 × 30 ช่อง ข้อมูลสมมติ บนจอจริงมีสี

```
 บทสนทนา ...                       │ 🗂 Session  7 turns · 21m52s
                                   │
                                   │ 👥 login
                                   │ 📋 BA     ✓
                                   │ 🧭 Lead   ✓
                                   │ 🔨 Dev    2/3 ◀ ⏳ กำลังทำงาน…
                                   │ 🔍 Review
                                   │ 🔒 Sec
                                   │
                                   │ [1 ไฟล์ 16] [ 2 คำสั่ง 2 ]
                                   │ [ 3 test 1 ] [ 4 บล็อก 1 ]
                                   │ ────────────────────────────────
                                   │ ×6 hooks/register.tsx
                                   │ ×1 …/auth/login/LoginForm.tsx
                                   │ ...  (ยาวลงไปจนเต็มจอ)
 > พิมพ์ตรงนี้                        │ c: ล้าง · 1-4 แท็บ · ctrl+x x ปิด
```

- **ส่วนทีม** (ด้านบน) มาจาก team-flow: ✓ สีเขียว = เสร็จ, ◀ สีฟ้า = ขั้นปัจจุบัน, ⏳ สีเหลือง = agent กำลังทำงาน, ข้อความสีแดง = review/sec ตีกลับ ถ้าแถบเตี้ยจะย่อเหลือบรรทัดเดียว `👥 login · 🔨 Dev 2/3 ◀ ⏳Dev` ถ้าโปรเจกต์ไม่มี `.team/` หรือไม่ได้ติดตั้ง team-flow ส่วนนี้จะไม่แสดง
- **เมนู** กด `1`–`4` สลับแท็บ แสดงทีละหมวด:

| แท็บ | แสดง |
| --- | --- |
| `1 ไฟล์` | ไฟล์ที่แก้ (×จำนวนครั้ง, ใหม่สุดก่อน, path ยาวจะตัดหัวให้เห็นชื่อไฟล์) |
| `2 คำสั่ง` | คำสั่ง Bash ล่าสุด `✓` ผ่าน · `✗` พัง · `…` กำลังรัน |
| `3 test` | ผล test / lint / tsc / build `✓ ผ่าน` · `✗ พัง` |
| `4 บล็อก` | สิ่งที่ถูกบล็อก เช่นจาก [dev-guard](../dev-guard/) |

- **สูงเต็มจอ** รายการยืดจนถึงบรรทัดล่างสุด ถ้าไม่พอจะขึ้น `+N รายการ` บรรทัดปุ่มอยู่ล่างสุดเสมอ ถ้าจอสูง 32 บรรทัดขึ้นไปจะโชว์ 2 รายการล่าสุดของแท็บอื่นต่อด้านล่างด้วย
- แถบ token / limit ไม่อยู่ในเมนูนี้ อยู่ใต้ช่องพิมพ์ด้วย [dev-status](../dev-status/)

## ขนาดจอ

| จอ | เมนูทำอะไร |
| --- | --- |
| โหมด fullscreen และกว้าง ≥ 120 ช่อง | เกาะด้านขวา กว้างประมาณ 28% ของจอ (34–48 ช่อง) |
| ย่อจอจนแคบกว่า 120 หรือออกจาก fullscreen | ซ่อนเองพร้อมแจ้ง "ซ่อน dashboard เพราะจอแคบ" และกลับมาเองเมื่อขยายจอ |
| จอเล็กแต่พิมพ์ `/dashboard` | เปิดแบบย่อเหนือช่องพิมพ์ 8 บรรทัด กด Esc ปิด |

ถ้าคุณปิดเอง (`ctrl+x x` หรือ `/dashboard close`) จะไม่เด้งกลับมาจนกว่าจะพิมพ์ `/dashboard`

Claude Code ไม่เปิด pane ให้เองถ้าจอแคบกว่า 144 ช่อง ถ้าจอกว้าง 120–143 ช่อง ให้พิมพ์ `/dashboard` หนึ่งครั้ง หลังจากนั้นจะเปิดเองได้ตั้งแต่ 110 ช่องขึ้นไป

## ใช้งาน

| คำสั่ง / ปุ่ม | ทำอะไร |
| --- | --- |
| `/dashboard` | เปิดเมนู |
| `/dashboard close` หรือ `ctrl+x x` | ปิดเมนู |
| `1` `2` `3` `4` | สลับแท็บ |
| `c` | ล้างรายการทั้งหมด |

`/clear` เริ่มนับใหม่

## ตั้งค่า (`/config`)

| ค่า | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `autoOpen` | `true` | เปิดเมนูเองเมื่อจอกว้างพอ |
| `minColumns` | `120` | ซ่อนเมนูเมื่อจอแคบกว่านี้ |
| `sidebarColumns` | `0` | ความกว้างของเมนู (`0` = อัตโนมัติ ~28% ของจอ) ถ้าลากปรับเองจะยึดตามที่ลาก |
