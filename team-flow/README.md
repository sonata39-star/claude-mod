# team-flow 👥

บอกว่างานตอนนี้อยู่ขั้นไหนของทีม agent: BA → Lead → Dev → Review → Sec แสดงในเมนูด้านขวาคู่กับ [dev-dashboard](../dev-dashboard/) หรือเป็นแถบเหนือช่องพิมพ์ถ้าเมนูขวาไม่ได้เปิดอยู่

```bash
claude plugin marketplace add sonata39-star/claude-mod   # ครั้งเดียว
claude plugin install team-flow@claude-mod
```

## หน้าตา

> ตัวอย่างวาดจากผลที่ test ตรวจ บนจอจริงมีสี

**ในเมนูด้านขวา** (ติดตั้ง dev-dashboard และจอกว้างพอ) อยู่ด้านบนของเมนู:

```
👥 login
📋 BA     ✓
🧭 Lead   ✓
🔨 Dev    2/3 ◀ ⏳ กำลังทำงาน…
🔍 Review
🔒 Sec
```

ถ้าเมนูเตี้ยจะย่อเหลือบรรทัดเดียว: `👥 login · 🔨 Dev 2/3 ◀ ⏳Dev`

**เป็นแถบเหนือช่องพิมพ์** เมื่อเมนูขวาไม่ได้แสดง (จอเล็ก, ปิดเมนูไว้ หรือไม่ได้ติดตั้ง dev-dashboard):

```
👥 login  📋 BA ✓ → 🧭 Lead ✓ → 🔨 Dev 2/3 ◀ → 🔍 Review → 🔒 Sec
⚡ 🔨 Dev กำลังทำงาน…
```

พอเมนูขวากลับมา แถบนี้จะหลบไปเอง ไม่แสดงซ้ำสองที่

- `✓` สีเขียว = ขั้นที่เสร็จแล้ว, `◀` สีฟ้า = ขั้นปัจจุบัน, `2/3` = task ที่ติ๊กแล้วจากแผนของ Lead
- `⏳` / `⚡` = มี agent ทีมกำลังทำงานอยู่
- review ได้ FAIL หรือ sec ได้ BLOCK จะย้อนกลับไปที่ Dev พร้อมข้อความสีแดง "แก้ตาม review/sec"

## อ่านจากไหน

ใช้ไฟล์ใน `.team/` ของโปรเจกต์ที่ agent ทีม (`ba`, `lead`, `dev`, `sec`, `pm`) เขียนไว้:

| ไฟล์ | ใครเขียน | ใช้ดูอะไร |
| --- | --- | --- |
| `req-<งาน>.md` | BA | requirement เสร็จแล้ว |
| `plan-<งาน>.md` | Lead | task `[ ]` / `[x]` ใต้ "## Task Breakdown" |
| `dev-report-<งาน>.md` | Dev | ส่งงานแล้ว |
| `review-<งาน>.md` | Lead | `**Verdict**: PASS / FAIL` |
| `sec-<งาน>.md` | Sec | `**Verdict**: APPROVE / BLOCK / APPROVE_WITH_NOTES` |
| `dlc-<งาน>.md` | PM | งานจาก PM |

แสดงงานที่มีไฟล์เปลี่ยนล่าสุด ถ้าโปรเจกต์ไม่มี `.team/` จะไม่แสดงอะไรเลย

## ใช้งาน

- `/team-flow` ซ่อน / แสดงแถบเหนือช่องพิมพ์ หรือกดปุ่มซ่อนบนแถบ
- อยู่ร่วมกับแถบของ mod อื่นได้ (เช่น neko)
- ติดตั้งตัวเดียวก็ใช้ได้ จะแสดงเป็นแถบเหนือช่องพิมพ์
